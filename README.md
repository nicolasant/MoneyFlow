# 💰 Sistema de Controle Financeiro

Um sistema completo para gerenciamento financeiro pessoal, desenvolvido para auxiliar no controle de receitas, despesas, dívidas e investimentos de forma prática, moderna e intuitiva.

---

# 🚀 Sobre o Projeto

O projeto foi criado com o objetivo de oferecer uma visão clara da vida financeira do usuário, permitindo registrar movimentações financeiras e acompanhar automaticamente o saldo disponível.

A plataforma conta com um dashboard moderno, histórico de transações e organização por categorias, tornando o gerenciamento financeiro mais eficiente.

---

# 🖥️ Dashboard do Sistema

## 📊 Visão Geral Financeira

O dashboard apresenta:

- Total de receitas
- Total de despesas
- Total de dívidas
- Total de investimentos
- Saldo disponível calculado automaticamente
- Gráfico de distribuição financeira
- Histórico completo das movimentações
